# 퇴근 찍었는데 던전 1층입니다만? (악덕기업 100층 지옥 탈출기)

금요일 18:00, 퇴근 지문기에 손가락을 댄 순간 사옥이 100층 악덕기업 마탑으로 변합니다. 김대리는 장비와 스킬을 세팅한 뒤 자동 등반·방치 파밍으로 옥상 헬리패드까지 올라가야 진짜 퇴근할 수 있습니다.

K-직장인 블랙코미디 하드코어 방치형 텍스트 시뮬레이션 RPG입니다. 전투 엔진, 메이플식 25성 스타포스(파괴 없음), 스킬 진화 분기, 접두어 RNG 보스, 4단계 난이도(일반/하드/헬/본사 마탑 200층), 타임루프 초월이 한 화면에서 돌아갑니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:43127](http://127.0.0.1:43127) 을 엽니다.

프로덕션 빌드:

```bash
npm run build
npm start
```

## 조작

- **지옥 탈출 전투**: 자동 턴제 전투. 등반/파밍 토글, 일시정지, 스킬 수동 발동
- **김대리 스펙**: 근성·눈치·처세술·월급루팡 투자, 스킬 진화 A/B 무료 전환
- **서류 가방**: 장착/해제/판매/등급 일괄판매, 스펙 비교, 스타포스 25성 개조소
- **타임루프**: 야근 트라우마로 영구 특성 구매, 난이도 전환, 수동 회귀

세이브는 브라우저 LocalStorage에 자동 저장됩니다. 자리를 비우면 최대 18시간, 효율 65%의 쪽잠(오프라인) 보상이 돌아옵니다.

## 스택

Next.js (App Router), React, TypeScript, Tailwind CSS, Lucide React
